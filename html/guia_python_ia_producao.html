Visão geral

Produção é mais do que “o modelo respondeu”

Um protótipo normalmente recebe uma pergunta e devolve uma resposta. Em produção, também precisa lidar com erros, muitas solicitações ao mesmo tempo, dados persistentes, tarefas demoradas, segurança, atualizações e métricas.

Exemplo de produto

Um assistente que responde dúvidas sobre documentos institucionais. Ele recebe a pergunta, busca trechos relevantes, gera a resposta, registra a conversa e informa se está lento ou indisponível.

Caixa de ferramentas

Oito peças que trabalham juntas

Cada ferramenta resolve um problema diferente. Não é obrigatório usar todas desde o início: adote-as conforme o produto ganha usuários e responsabilidade.

LangChain

Orquestração de LLM

Organiza prompts, ferramentas, memória e fluxos RAG.

Ex.: chatbot consulta PDFs

FastAPI

API de alto desempenho

Expõe o protótipo por HTTP para web, app ou outros sistemas.

Ex.: POST /perguntar

Pydantic

Validação de dados

Confere formatos antes que dados incorretos cheguem ao modelo.

Ex.: pergunta: str

Celery + Redis

Fila de tarefas

Tira trabalhos longos do caminho da requisição principal.

Ex.: indexar 10 mil arquivos

PostgreSQL

Dados confiáveis

Armazena usuários, conversas, permissões e registros de auditoria.

Ex.: histórico por usuário

Docker

Empacotamento

Entrega a aplicação com dependências e configuração reproduzíveis.

Ex.: mesmo ambiente no servidor

Nginx

Entrada da aplicação

Termina HTTPS, encaminha tráfego e pode distribuir carga.

Ex.: domínio + certificado

Prometheus

Métricas e alertas

Mede saúde e desempenho para detectar problemas cedo.

Ex.: alerta de latência

Exemplo integrado

Uma pergunta entra. O que acontece?

Este cenário mostra como as peças se conectam em um assistente de documentos.

Fluxo de uma solicitação

  1. Cliente → Nginx: a pessoa acessa a aplicação por HTTPS.
  2. Nginx → FastAPI: a API recebe /perguntar.
  3. Pydantic: valida se a pergunta e o identificador do usuário são válidos.
  4. LangChain: recupera contexto e chama o modelo de IA.
  5. PostgreSQL: guarda a pergunta, a resposta e metadados.
  6. Prometheus: registra tempo de resposta e possíveis falhas.

API mínima com FastAPI e Pydantic

Uma base simples para receber uma pergunta. Em um projeto real, a função responder chamaria o seu fluxo de IA.

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Pergunta(BaseModel):
    texto: str
    usuario_id: int

@app.post("/perguntar")
def responder(item: Pergunta):
    # aqui entra LangChain ou outro fluxo de IA
    resposta = f"Recebi: {item.texto}"
    return {"resposta": resposta}
